Setup

  1. 1VisitBrexand log in to the account you want to connect
  2. 2Go to the Brex developer/API token settings for the company you want to connect
  3. 3Create an API token with these read-only scopes: accounts.cash.readonly, accounts.card.readonly, transactions.cash.readonly, transactions.card.readonly
  4. 4Copy the token and add it as a named connection below. Sure stores the token only for syncing this family.

Use a separate named connection for each Brex company/API token you want to sync. Leave Base URL blank for production. Staging is limited to Brex-approved testing and does not work with customer tokens.
