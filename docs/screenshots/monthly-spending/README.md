# Monthly spending PR screenshots

All images show synthetic data. Desktop/mobile web captures come from the real
Capybara monthly-spending flow; the dark tablet capture comes from the isolated
local preview. The Flutter capture uses the current `MonthlySpendingCard` and
fixture data in a temporary widget-test harness with the app fonts loaded.
The harness is not committed. No physical-device build is represented.

The PR description draft is in `docs/plans/monthly-spending-pr.md`. Its relative
image paths render in the branch document. When publishing the actual GitHub
PR body, resolve these paths to absolute raw URLs using the pushed repository
and commit so the images also load inside the PR conversation.
