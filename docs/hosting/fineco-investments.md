# Fineco investment preview

Fineco is a self-hosted preview for family administrators. First enable **Settings → Preferences → Preview features**; opening the Fineco login URL without that preference redirects home. Then use **Settings → Providers → Fineco** or choose Fineco when adding an **Investment** account.

Capture is controlled by the code capability `Provider::Fineco.verified_identity_contract?`; request parameters and environment variables cannot enable it. With the capability disabled, the browser is available for login and MFA diagnostics only. Sure does not inspect browser network traffic, read Fineco cookies or portfolio responses, persist the bank session, or import investments, and the UI reports that capture is not ready.

With the capability enabled, sign in to Fineco in the temporary browser and complete its challenge. After approval, Sure automatically reads the account list from an exact authenticated private page. When it finds exactly one account and one dossier, it submits their indices to the existing server callback. The callback independently verifies the bank business identity and portfolio, then encrypts and persists the session and snapshot. On success, Sure closes the viewer and confirms the connection; no manual **Portafoglio Sintesi** navigation is needed for this unambiguous case. If there are multiple accounts or dossiers, Sure does not guess. The user can select the desired context in Fineco and let the existing exact portfolio-request path capture its indices.

The observed account-list response contained one account and one dossier. Their business `number` values were positive JavaScript-safe integers; the selection `index` values were numeric integers from 0 through 999999. Sure's versioned identity fingerprint hashes the canonical account and dossier business-number pair, excluding selection indices, labels, and mutable flags. The next attended capture still needs to verify cookie-only Ruby replay and the real persistence/import callback. Unattended expiry and refresh also remain unverified.

The browser session cookie is a full Fineco web-session credential, not a bank-issued read-only token; fixed account and portfolio GETs do not narrow its authority. Fineco sessions can expire or require SCA again, so a manual reconnect may be needed. Sure does not promise an indefinitely renewable session.

When automatic synchronization is enabled, the worker schedules active Fineco connections every 20 minutes. A portfolio response that omits quote fields receives one bounded retry within the existing request deadline. If prices are still unavailable, Sure keeps the previous complete holdings and balance, reports the missing-price condition, and leaves the connection eligible for the next scheduled attempt. It does not derive missing prices or import a partial snapshot.

Valid session-cookie replacements are stored encrypted. If an identity-verified read rotates the cookie and a later portfolio read fails, Sure retains the validated replacement only when the selected bank account and dossier still match the saved connection. An authentication failure still requires reconnection; periodic reads do not guarantee that Fineco will extend an absolute session limit.

The intended import creates a separate EUR Investment account for securities. Existing Enable Banking cash and deposit accounts stay separate and unchanged; Fineco's securities account reports zero cash. Snapshot history is not trade history: Sure does not invent purchases or sales to fill gaps between snapshots.

Once capture is enabled, the importer will accept only a complete, unfiltered portfolio summary with EUR totals. Every position must have a valid ISIN, a supported position type (`stock`, `equity`, `etf`, or `bond`), and a supported exchange venue (`XETR`/`XETRA` or `ETLX`). A position's quote currency may differ from EUR, but the imported Investment account and total remain in EUR. Missing or inconsistent totals, filters, unsupported positions, identity conflicts, and incomplete responses reject the whole snapshot and keep prior holdings and balance in place.

Sure calculates each holding's EUR unit price and cost basis from the reported EUR market/book value divided by the reported quantity, including nominal-unit bonds. Fineco's original quote and quote currency remain provider metadata, so a per-unit EUR value in Sure may differ from Fineco's clean or percentage-based quote.

The identity fingerprint uses a versioned hash of the canonical account and dossier business-number pair. Selection indices locate the pair for each request but do not identify it; labels and mutable dossier flags are not part of the fingerprint. A changed or unverifiable pair blocks import, so Sure will not silently move snapshot history to another account or dossier.

**Stop syncing** clears the stored Fineco session while retaining the Fineco item, Investment account, holdings, and snapshot history. Reconnect to resume updates. For the self-hosted browser runtime's operator requirements and hardening, see [Fineco browser login runtime](fineco-browser-runtime.md).
