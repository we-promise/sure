# Sure roadmap

This file is the curation and triage source for the public roadmap page in the
Sure website repository. Keep phases and items in the order they should appear
publicly. Changes to this file are reviewed through pull requests.

The website reads this deliberately small format:

- Each phase starts with `## Phase: Name`, followed by one `Description:` line.
- Each item starts with `### Item: Name`, followed by `Status:` and
  `Description:` lines.
- Status must be one of `In progress`, `Planned`, or `Exploring`.
- GitHub issue and PR links are intentionally omitted for now.

-->

## Phase: Short term

Description: Stabilize and polish the core.

### Item: Reliability, performance, and technical debt
Status: In progress
Description: Make the everyday experience dependable, fast, and easier to maintain.

### Item: Web UX/UI polish
Status: Planned
Description: Refine the web experience around the details that make Sure feel clear and cohesive.

### Item: AI controls and transparency
Status: Planned
Description: Give people understandable controls and visibility into how AI works with their data.

### Item: Documentation and onboarding
Status: Planned
Description: Help new people get value from Sure quickly, whether they use the hosted app or self-host it.

### Item: Mobile app planning and delivery
Status: Planned
Description: Establish and ship a thoughtful mobile experience for managing money on the go.

### Item: Quality-focused release cadence
Status: Planned
Description: Build a sustainable rhythm for shipping improvements with confidence.

## Phase: Medium term

Description: Expand personal-finance capability.

### Item: First-class AI
Status: Exploring
Description: Make AI a useful, transparent part of the core financial workflow.

### Item: Transaction intelligence
Status: Planned
Description: Turn transaction data into better organization, context, and decisions.

### Item: Savings, retirement, and investments
Status: Planned
Description: Support more of the financial picture beyond day-to-day budgeting.

### Item: Scenario simulation
Status: Exploring
Description: Help people understand the possible outcomes of financial choices before they make them.

### Item: Localization and country support
Status: Planned
Description: Make Sure useful and natural for people across more countries, currencies, and financial systems.

### Item: Themes and customization
Status: Planned
Description: Let people shape their financial workspace to fit the way they think and work.

## Phase: Long term

Description: Open the platform carefully.

### Item: External-agent integration and execution
Status: Exploring
Description: Create safe, permissioned ways for outside agents to work with Sure.

### Item: Agent-assisted cleanup and memory
Status: Exploring
Description: Use agents to reduce financial-data maintenance while keeping people in control.

### Item: Polished mobile ecosystem
Status: Planned
Description: Grow mobile into a complete, reliable part of the Sure experience.

### Item: Improved macOS and desktop experience
Status: Planned
Description: Make Sure feel at home across desktop platforms and workflows.

### Item: Business finance support
Status: Exploring
Description: Carefully extend Sure to the needs of people managing business finances.
