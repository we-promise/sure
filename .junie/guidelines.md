# Junie Guidelines

Read and follow the shared [repository guidelines](../AGENTS.md) before making changes or reviewing code. Follow the linked guides in `AGENTS.md` for the area you are changing.

This file preserves the legacy Junie guidelines path. Current Junie versions can read the root `AGENTS.md` directly; IDE users can also set Guidelines path to `AGENTS.md`. Keep shared guidance in the root file and its linked guides rather than copying it here or creating `.junie/AGENTS.md`.
